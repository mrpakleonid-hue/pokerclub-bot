# Castle Club

Telegram-бот и веб-приложение покерного клуба (игра не на деньги, 18+): запись на турниры, таймер блайндов, учёт ребаев и аддонов, касса, журнал долгов, бонусы, рейтинг, роли персонала.

## Как устроено

- `core.js` — вся логика клуба. Состояние строится из **журнала событий**: каждое действие (запись, выдача ребая, оплата, правка уровня) — отдельная запись, которая никогда не меняется и не удаляется. Это даёт полный аудит и позволяет позже синхронизировать облако с сервером в клубе.
- `server.js` — веб-сервер без фреймворков: API, проверка входа через Telegram, вход по коду для игроков без Telegram, вебхук бота, рассылка уведомлений.
- `store.js` — хранение журнала: PostgreSQL (`DATABASE_URL`) или файл `data/events.jsonl` для локального запуска.
- `public/` — интерфейс. Один и тот же экран открывается в Telegram (Mini App) и в обычном браузере.

## Переменные окружения

| Переменная | Что это |
| --- | --- |
| `BOT_TOKEN` | Токен бота от @BotFather (секрет) |
| `DATABASE_URL` | Строка подключения к PostgreSQL |
| `SESSION_SECRET` | Случайная строка для подписи сессий (секрет) |
| `PUBLIC_URL` | Адрес сайта; на Render подставляется сам (`RENDER_EXTERNAL_URL`) |

## Первый запуск

Первый человек, который откроет приложение, автоматически становится **управляющим**. Остальные регистрируются как игроки; роли назначаются во вкладке «Роли».

## Локально

```
node server.js          # без DATABASE_URL пишет журнал в data/events.jsonl
npm test                # сквозной тест логики
```
